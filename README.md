# Cosmic Developer

Create a premium personal portfolio website for **Md. Sabbir Hossain Dewan**, a Front-End Developer.

The website must have a **deeply cinematic, monochromatic, black-and-white deep-space aesthetic inspired by the atmosphere, cinematography, scale, typography, silence, and visual language of the movie *Interstellar*.**

This should NOT look like a normal developer portfolio with a space background added to it.

The entire experience should feel like **entering a mysterious universe and discovering the developer inside it.**

---

# 1. CORE VISUAL DIRECTION

The dominant visual language is:

**BLACK. WHITE. SHADOW. LIGHT. SPACE. SILENCE. SCALE.**

Use an almost entirely black interface.

### Color palette

Primary:

* Pure black
* Near-black
* Charcoal
* Very dark gray

Secondary:

* Soft white
* Off-white
* Light gray
* Metallic gray

Avoid colorful gradients.

Avoid blue neon.

Avoid purple neon.

Avoid cyan neon.

Avoid RGB.

Avoid colorful cyberpunk effects.

The only "color" should come from extremely subtle grayscale lighting.

The website should feel almost entirely **black and white**.

---

# 2. INTERSTELLAR-INSPIRED ATMOSPHERE

The visual atmosphere should communicate:

* Vastness
* Isolation
* Mystery
* Exploration
* Gravity
* Time
* Distance
* Human curiosity
* Technology
* The unknown

Use subtle visual references to:

* Deep space
* Distant stars
* Black holes
* Gravitational fields
* Orbital paths
* Space dust
* Astronomical diagrams
* Distant planets
* Wormhole-like geometry
* Time and distance
* Minimal scientific interfaces

However, keep everything **abstract and original**.

Do NOT copy movie scenes.

Do NOT use movie screenshots.

Do NOT use movie logos.

Do NOT use copyrighted movie assets.

Do NOT recreate recognizable movie characters.

The goal is to capture the **cinematic atmosphere**, not copy the film.

---

# 3. ABSOLUTELY NO GENERIC FUTURISTIC DESIGN

Do NOT create:

* Cyberpunk UI
* Gaming interface
* Hacker aesthetic
* Crypto aesthetic
* Neon dashboard
* Excessive glassmorphism
* Bright gradients
* Huge glowing cards
* Rainbow effects
* Excessive 3D
* Cartoon planets
* Overloaded HUD elements

Instead use:

**darkness + typography + negative space + cinematic lighting + subtle astronomy.**

# 25. FINAL DESIGN TEST

Before finishing, ask yourself:

Does this look like a normal developer portfolio?

If YES → redesign it.

Does this look like a cyberpunk website?

If YES → remove the neon/futuristic elements.

Does it feel colorful?

If YES → remove the color.

Does it feel crowded?

If YES → add more negative space.

Does it feel like a gaming website?

If YES → simplify it.

Does it feel like a cinematic journey through an enormous black universe?

If YES → this is the correct direction.
